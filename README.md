# 暇つぶし大全

公開サイト: https://wings0178.github.io/hima-taizen/

恐竜ランナー、テトリス、弾幕シューティングの静的ゲームサイトです。画像・音声素材、外部ライブラリ、通信、アカウント登録は不要です。`index.html` を開いても遊べます。ランキング保存は既存版と同じく無効です。

## 操作

- 恐竜ランナー: Space / ジャンプボタン。
- テトリス: 方向キーで移動・回転、Spaceでハードドロップ、Shift / Cでホールド。スマホはタップで回転、左右ドラッグで移動、下フリックでハードドロップ、上フリックでホールド。
- 弾幕シューティング: 方向キー / WASD、スマホはゲーム画面のドラッグまたは十字キーで移動。射撃は自動、Shiftで低速、X / ボムボタンで弾を消去。残機3・ボム3、全3ウェーブ。キャラクターや素材は独自のものです。
- 各ゲームの一時停止: P / Esc / 一時停止ボタン。ウィンドウを離れた場合も一時停止し、再開操作で戻ります。
- タイトルの「操作方法」を押すと説明を開閉できます。弾幕ゲームの下端の赤いマーカーは敵の横位置を示します。

## ショートモード

「ショートモード」を押すと選択中のゲームが開始します。ゲーム画面を大きく上にスワイプすると次、下にスワイプすると前のゲームに切り替わり、自動で開始します。指を動かしている間も画面が上下に動き、離すと切り替わります。最後のゲームから先頭へ循環します。専用の切り替えボタンや帯を押す必要はありません。

PCはゲーム画面上でマウスホイールを下に回すと次、上に回すと前へ切り替わります。ホイールの連続イベントや慣性による飛びすぎを抑えます。マウスでの上下ドラッグとPageDown / PageUpにも対応します。

ショートモードでは大きな上下フリックを切り替え、小さなフリックやゆっくりしたドラッグをゲーム操作に分けます。テトリスの短い上下フリックはホールド・ハードドロップ、左右ドラッグは移動です。弾幕の上下移動はゆっくりドラッグするか十字キーを使えます。切り替え判定中の入力はゲームへ渡さず、切り替えスワイプでブロックや自機を動かしません。恐竜はゲーム画面のタップでもジャンプできます。通常モードのゲーム操作は従来どおりです。

タイトル・結果画面の余白でもスワイプできます。開いた操作説明の上では説明をスクロールします。「一覧に戻る」で通常のタイトル画面に戻ります。切り替え時の進行はリセットされます。

表示領域は通常モードと同じ広さです。切り替え時の240msの上下スライドは、ゲーム画面をコピーした表示専用レイヤーを動かします。実際のキャンバス、入力座標、ゲームの更新速度は動かしません。連続操作時は前の演出を取り消し、「視差効果を減らす」等の設定がある環境では演出を省略します。

## 開発

`GameScene` を継承し、独自のイベントは `removeListeners()` で解除してください。`showUI()` / `hideUI()` が前のループと入力を停止します。ループでは終了・一時停止後に次のフレームを予約しないでください。キャンバスの表示寸法はCSSで管理し、`canvasPoint()` で余白を除いたタッチ座標を取得します。

公開はGitHub Pagesの `main` ブランチのルートです。ゲーム追加後はスマホ幅、横向き、連続切り替え、再開始、ポーズ、タッチの競合を確認してください。

## 回帰テスト

Node.js環境で `npm install`、`npx playwright install chromium`、`npm test` を実行します。テスト用のローカルサーバーは自動で起動・終了します。既存のEdgeを使う場合は環境変数 `BROWSER_CHANNEL=msedge` を設定できます。`GAME_URL` を設定すると公開サイトも同じ項目で検証できます。

テストは3ゲームの操作、90回の切り替え、処理の重複、ポーズと再開始、スマホの実タッチイベント、テトリスの座標変換、キャンセル操作、縦横の画面サイズを確認します。スクリーンショットと結果は `artifacts/` に出力します。iPhone実機での確認は別途必要です。
