# 暇つぶし大全

公開サイト: https://wings0178.github.io/hima-taizen/

恐竜ランナー、テトリス、弾幕シューティング、ボール発射ゲームの静的ゲームサイトです。3Dライブラリと効果音は同梱しており、プレイ時の外部通信やアカウント登録は不要です。`index.html` を開いても遊べます。ランキング保存は既存版と同じく無効です。

## 操作

- 恐竜ランナー: Space / ジャンプボタン。
- ボール発射ゲーム: 画面下のボールを下に引いて離すと発射。引く長さで強さ、左右への引っ張りで狙いを調整します。飛ぶ軌道を点線で表示します。キーボードは← →で狙い、Space長押し・離すで発射。3球で積み木を崩し、「次の積み方」で次のラウンドへ。ピラミッド・壁・交互積み・橋・塔の5種類からランダムに選び、前のラウンドと同じ積み方は続けません。崩れた個数がスコアです。音のON/OFFはこのブラウザーに保存します。3D描画にはWebGL2対応ブラウザーが必要です。
- テトリス: 方向キーで移動・回転、Spaceでハードドロップ、Shift / Cでホールド。スマホはタップで回転、左右ドラッグで移動、下フリックでハードドロップ、上フリックでホールド。
- 弾幕シューティング: 方向キー / WASD、スマホはゲーム画面のドラッグまたは十字キーで移動。射撃は自動、Shiftで低速、X / ボムボタンで弾を消去。残機3・ボム3、全3ウェーブ。キャラクターや素材は独自のものです。
- 各ゲームの一時停止: P / Esc / 一時停止ボタン。ウィンドウを離れた場合も一時停止します。4ゲーム共通で「一時停止」と表示し、ゲーム画面のどこかをタップ／クリックすると再開します。再開タップはゲーム操作として扱いません。P / Esc / 再開ボタンも使えます。
- タイトルの「操作方法」を押すと説明を開閉できます。弾幕ゲームの下端の赤いマーカーは敵の横位置を示します。

ボール発射ゲームはThree.js 0.180.0とcannon-es 0.20.0（MIT）による3D描画・剛体物理を使います。効果音はKenneyのCC0素材（木の衝突、食器の衝突、発射の風切り音）。WAVと埋め込み音声を同梱し、音の読み込み失敗でもゲームは続けられます。衝突音の間隔・同時発音数・音量を制限し、一時停止・ゲーム切り替えで音を停止します。[素材・ライセンス](games/ball-launch/LICENSES.md)に出典と原ライセンスを保存しています。

## ショートモード

「ショートモード」を押すと選択中のゲームが開始し、画面の左下にスライムが現れます。スライムを押しながら上に引いて離すと次、下に引いて離すと前のゲームに切り替わります。初めて表示するゲームは自動で開始します。最後のゲームから先頭へ循環します。

引くとスライムが伸び、切り替え先のゲーム名と画面の追従表示が現れます。十分引くと色が変わり、離すと切り替わります。タップ、短い引っ張り、横への引っ張り、元の位置に戻して離す操作では切り替わりません。ゆっくり引いても使えます。離した後は縮んで元の形に戻ります。

スライムから始めた操作だけを切り替えに使います。ゲーム画面のタッチはそのままゲームへ渡すため、テトリスのホールド・ハードドロップや弾幕の上下ドラッグでゲームが切り替わることはありません。恐竜はジャンプボタンまたは画面タップでジャンプできます。

PCはゲーム画面上でマウスホイールを下に回すと次、上に回すと前へ切り替わります。ホイールの連続イベントや慣性による飛びすぎを抑えます。スライムのマウスドラッグとPageDown / PageUpにも対応します。

一覧の「設定」でスライムの位置を左下・右下から選べます。初期値は左下です。設定はこのブラウザーのlocalStorageに保存し、再読み込み後も保持します。設定画面を開くとプレイ中のゲームを一時停止し、閉じると元の状態に戻します。保存できない環境ではその旨を表示し、今回の設定変更は有効にします。

設定の「ゲームスロット」でショートモードに出すゲームを選びます。1つ以上の選択が必要です。外したゲームも通常モードでは遊べます。

「途中の状態を残す」は初期状態でONです。切り替えたゲームの盤面・位置・残機・スコア・タイマーを保持し、一巡して戻ると中断した状態を「一時停止」で表示します。ゲーム画面をタップすると続きから再開します。OFFでは切り替えのたびに最初から開始します。進行はページを開いている間だけ保持し、再読み込みで消えます。ゲームスロット・ON/OFF・スライム位置の設定は再読み込み後も残ります。

スライムは80pxで、タイトル・結果画面でも使えます。「一覧に戻る」で通常のタイトル画面に戻り、スライムは非表示になります。タイトルに戻る・再開始・ゲーム終了時は、そのゲームの中断状態を破棄します。

表示領域は通常モードと同じ広さです。引っ張り中と切り替え時の上下スライドは、ゲーム画面をコピーした表示専用レイヤーを動かします。実際のキャンバス、入力座標、ゲームの更新速度は動かしません。連続操作時は前の演出を取り消し、「視差効果を減らす」等の設定がある環境では待機・復帰・スライドの演出を省略します。

## 共通のゲーム画面

ゲーム画面・上の操作欄・下の操作欄を共通のレイアウトで管理します。同じ画面サイズなら、4ゲームの表示枠は同じ位置・幅・高さになり、タイトル・プレイ・一時停止・結果でも変わりません。操作ボタンがないゲームでもその欄の広さを保持します。スライムはゲーム画面の外の下部操作欄に固定し、操作ボタンやゲーム本体を遮りません。

ゲーム内部の解像度と縦横比は維持し、共通の枠に収まる最大サイズで表示します。画像の引き伸ばし・切り取りはしません。小さいスマホや横向きでは操作欄をコンパクトにし、ゲームの表示面積を確保します。横向きの十字キーは一列に並びます。

## 開発

新しいゲームも同じ `#game-stage` を使います。`canvas.width` / `canvas.height` はゲーム内部の座標にのみ使い、外側の表示枠・余白・スライム位置をゲームごとに変更しないでください。操作ボタンは `super('ゲーム名', {controls: ['dpad', 'bomb']})` のように宣言します。利用できる共通操作は `dpad`、`jump`、`bomb`、`sound` です。指定がない場合は空になります。表示のルールは [AGENTS.md](AGENTS.md) を参照してください。

`GameScene` を継承し、独自の入力登録は `attachListeners()` にまとめ、開始・中断からの復帰時に呼び出します。`removeListeners()` で対応するイベントを解除してください。中断は既存のインスタンスを保持して更新・入力だけを止め、復帰時は初期化せず一時停止で表示します。一時停止の表示とタップ再開は共通処理を使ってください。`showUI()` / `hideUI()` が前のループと入力を停止します。ループでは終了・一時停止後に次のフレームを予約しないでください。キャンバスの表示寸法はCSSで管理し、`canvasPoint()` で余白を除いたタッチ座標を取得します。

公開はGitHub Pagesの `main` ブランチのルートです。ゲーム追加後はスマホ幅、横向き、連続切り替え、再開始、ポーズ、タッチの競合を確認してください。

## 回帰テスト

Node.js環境で `npm install`、`npx playwright install chromium`、`npm test` を実行します。テスト用のローカルサーバーは自動で起動・終了します。既存のEdgeを使う場合は環境変数 `BROWSER_CHANNEL=msedge` を設定できます。`GAME_URL` を設定すると公開サイトも同じ項目で検証できます。

テストは4ゲームの操作、90回の切り替え、処理の重複、ポーズと再開始、スマホの実タッチイベント、テトリスの座標変換、キャンセル操作、縦横の画面サイズを確認します。ゲームスロットの循環・設定保存・全解除の防止、中断前後のゲーム状態の一致、再開タップとゲーム入力の分離、状態保持ON/OFF、スライム80pxと仮想キーの非重複も確認します。スクリーンショットと結果は `artifacts/` に出力します。iPhone実機での確認は別途必要です。

## テトリスのBGM・効果音

ゲーム開始後はFC音工場の「コロブチカ」を再生し、100pt以上になると次の小節でオーケストラ風の独自編曲へ切り替えます。切り替えは0.8秒のクロスフェードです。BGMのループはブラウザーの音声時計で再生し、曲末の余白・継ぎ目を整えています。ゲーム速度・採点方法は変更していません。

移動、回転、ホールド、ハードドロップ、固定、ライン消去、4ライン消去、ゲーム終了にSEを追加しました。「音：ON/OFF」でBGMとSEをまとめて切り替え、このブラウザーに保存します。ボール発射ゲームの音設定とは独立しています。一時停止・画面非表示・ゲーム切り替えで音を停止し、再開時は同じ曲の続きから再生します。新しいプレイでは通常BGMの先頭から始まります。

音声は初回の操作後に読み込みます。読み込み中・失敗時もゲームは続けられます。ブラウザーで音の再開が必要な場合は「音：再開」、読み込みが失敗した場合は「音：再試行」を押してください。音源・ライセンス・元ファイルの対応は [CREDITS.md](CREDITS.md) に記録しました。`tests/tetris-audio.cjs` で音声の実出力、ループ、スコア切り替え、消音保存、復帰、ローカル起動、読み込み遅延・失敗を確認できます。iPhone実機の確認は別途必要です。
